## Root Cause

All 20,328 records were generated by a single template seeder (`generateExpandedContent.js`) that:
1. Used a "Welcome to the comprehensive module for {subtopic}" intro for every record
2. Used "Fact N: Key indicator for UPSC" as importantFacts template
3. Used the same generic "### 1. Overview" structure for every explanation
4. Recycled identical example sentences across all records
5. Left `practiceMcqs` and `relatedTopics` empty in all records

The seeder produced structurally complete but content-hollow records.
A student reading any topic would see the same intro/structure regardless of subject.
